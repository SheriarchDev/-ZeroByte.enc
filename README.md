## English

ZeroByte.enc is a lightweight, local and open-source file encryption utility built for Windows using Python, PyQt6 framework, and the cryptography library. It is designed with a strong focus on data privacy, anti-forensics, and RAM security.

### 🛡️ Security Features
* Enterprise Encryption: Uses AES-256 GCM (Galois/Counter Mode). Files are cryptographically protected against tampering and byte corruption. An incorrect password instantly aborts the process without damaging the underlying data structure.
* Hardened Key Derivation: Master passwords are keys derived using PBKDF2HMAC with SHA256 and 100,000 iterations, making brute-force attacks computationally impossible.
* Memory Zeroing Protection: All plaintext password strings and cryptographic keys are forcefully overwritten with zeros in RAM (bytearray) immediately after use to defeat memory dumping tools.
* Secure Shredder & Masking: Before deletion, original source files are physically overwritten with random binary noise (os.urandom) to prevent forensic recovery via software like Recuva. Encrypted files are automatically masked under a generic .zrb extension to look like uninteresting system logs.
* 100% Offline & Transparent: Zero internet permissions. The source code is completely open for public audit to guarantee there are no backdoors or tracking.

### 📦 Reproducible Releases & Integrity
To ensure that the compiled executable matches the public source code, the official .exe release is built strictly using the Nuitka compiler (which translates Python directly into C++ binary code). You can verify the integrity of your download using the SHA-256 checksum below.

### 🛡️ VirusTotal, SmartScreen & False Positives [English]
When scanning the compiled zerobyte.exe via VirusTotal or running it through Windows SmartScreen, you may encounter generic heuristic warnings (such as !ml / Machine Learning alerts).

These are 100% False Positives caused by the following technical factors:
1. Behavioral Patterns: The utility performs secure shredding (low-level rewriting of disk sectors via os.urandom) and overwrites files with encrypted data. Automated security mechanisms often flag this as ransomware-like activity.
2. Compiler Overhead: Binary structures generated by the Nuitka compiler when translating Python directly to C++ are frequently misidentified by paranoid heuristic engines.
3. No Code Signing: The executable lacks a commercial Code Signing Certificate, triggering default Windows SmartScreen defense layers for "untrusted/unknown layout".

How to verify the safety yourself:
* Audit the Source: The source code zerobyte.py is fully transparent. You don't have to trust the pre-compiled binary — you can inspect the code for tracking or backdoors and compile the .exe yourself using the instructions provided.
* Verify the Integrity: Always check the SHA-256 hash of the downloaded binary using PowerShell: Get-FileHash .\zerobyte.exe -Algorithm SHA256 and match it with the release table.

## Русский

ZeroByte.enc — это легковесная, локальная утилита с открытым исходным кодом для надежного шифрования файлов на Windows, разработанная на базе Python, графического фреймворка PyQt6 и библиотеки cryptography. Программа создана с упором на приватность данных, противодействие компьютерной криминалистике (Anti-Forensics) и безопасность оперативной памяти.

### 🛡️ Особенности Безопасности
* Enterprise-шифрование: Использование эталонного алгоритма AES-256 GCM (Galois/Counter Mode). Файлы аппаратно защищены от модификации — неверный пароль мгновенно прерывает операцию, предотвращая порчу данных.
* * Усиленная деривация ключей: Мастер-пароли хэшируются через PBKDF2HMAC с использованием SHA256 и 100 000 итераций, что делает аппаратный брутфорс паролей невозможным.
* Защита оперативной памяти (Memory Zeroing): Все пароли и криптографические ключи принудительно затираются нулями в RAM (bytearray) сразу после выполнения операции, исключая их извлечение через дамперы памяти.
* Шредер оригиналов и Маскировка (.zrb): Перед удалением исходные файлы физически перезаписываются случайными байтами (os.urandom), что делает невозможным их восстановление через Recuva. Зашифрованные файлы маскируются под безликое расширение .zrb, напоминая внутренние логи системы.
* Абсолютная автономность: У программы нет и не может быть доступа к интернету. Код полностью открыт для любого аудита, что гарантирует честность и отсутствие скрытых бэкдоров.

### 📦 Воспроизводимость и Контроль целостности
Для того чтобы пользователи могли доверять готовому файлу, официальный релиз компилируется в жесткий машинный код C++ через компилятор Nuitka. Вы можете лично проверить, что скачанный .exe файл соответствует исходному коду, сравнив его SHA-256 хэш.

### 🛡️ VirusTotal, SmartScreen & False Positives [Русский]
При проверке скомпилированного файла zerobyte.exe на VirusTotal или при запуске через Windows SmartScreen вы можете столкнуться с предупреждениями (эвристическими детектами вида !ml / Machine Learning). 

Это на 100% ложные срабатывания (False Positives) нейросетей антивирусов по следующим техническим причинам:
1. Поведение программы: Утилита выполняет шрединг (извлечение низкоуровневых секторов и физическое затирание байтов на диске через os.urandom) и шифрует файлы, меняя их расширения. Для автоматических алгоритмов защиты это поведение идентично активности вредоносных троянов-вымогателей (*Ransomware*).
2. Особенности компилятора: Бинарный код, генерируемый компилятором Nuitka при трансляции Python в C++, часто вызывает подозрения у параноидальных эвристических движков.
3. Отсутствие цифровой подписи: Исполняемый файл не подписан коммерческим сертификатом разработчика (*Code Signing Certificate*), из-за чего система Windows SmartScreen считает его «неизвестным софтом».

Как лично убедиться в безопасности:
* Не верьте на слово: Исходный код zerobyte.py полностью открыт. Вы можете лично провести аудит каждой строчки, убедиться в отсутствии сетевых запросов или бэкдоров, а затем скомпилировать .exe самостоятельно на своем процессоре по инструкции выше.
* Проверяйте целостность (Хэш): Всегда сравнивайте хэш-сумму скачанного файла с таблицей релизов с помощью команды в PowerShell: Get-FileHash .\zerobyte.exe -Algorithm SHA256.
